⚙️ Diretriz Obrigatória: Atualização Automática do Histórico

Sempre que uma nova rotina de deserialização ou protocolo for revertido no binário cliente (SWGEmu.exe):

  1. Registre o novo lote de mensagens com seus metadados em swgdocs/data/reversal_history.json.
  2. Execute python scripts/update_history.py para recompilar esta página de histórico automaticamente.
  3. Gere a documentação técnica HTML correspondente e atualize all_packets.csv e packets_summary.json.
  4. Recompile os dados interativos com python scripts/generate_protocol_data.py para atualizar o Inspector.
