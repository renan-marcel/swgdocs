💡 Protocol Decoding Reference

SOE Protocol Wrapper
Packets starting with 0x0009 (Reliable Data) contain a 2-byte sequence number followed by the inner SWG payload and terminate with a 2-byte CRC16 checksum.
SWG Operand Count
Standard SWG messages begin with a 2-byte little-endian operand count: 0x0002 for standard packets, and 0x0005 for ObjControllerMessage wrappers.
Object Controller Messages
Opcode 0x80CE5E46 wraps game actions. It encapsulates Flags (4B), MessageId (4B), Target NetworkId (8B), TickCount (4B), and specific payload data.
