ObjectMenuSelectMessage::MESSAGE_TYPE (7CA18726) 7CA18726 📋

C→S (Client) 100% Complete Sample: present Section: SWG Protocols Type: Client Packet
✅ Verified via Binary Analysis (SWGEmu.exe): This payload structure and deserialization sequence has been fully reversed and verified against the client binary using Binary Ninja and Rea decompiler evidence.
Client-to-server radial interaction message sent when a player selects a specific radial menu option on a world object, NPC, item, or terminal.

Radial Menu Mapping: SelectedMenuItem maps to the radial menu action ID populated during the preceding ObjectMenuResponse baseline/controller interaction.
